# Localized Steam invitation errors

Production overlay-readiness error dialogs in German, Japanese, Simplified Chinese, Brazilian Portuguese and Basque. Each image shows the complete instructions and Retry/Back actions. Japanese and Chinese use the production regional-font configuration; the three added glyphs preserve all prior subset coverage.

Captured hidden and muted using a development-only Steam readiness response double. These images demonstrate translated UI and text rendering, not a live invitation, guest connection or a macOS capture fix.
